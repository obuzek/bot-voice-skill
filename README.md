# bot-voice-skill

Want to strip out the personality of your chatbot? Miss the bots of old? Try this.

Much has been said about AGI and whether or not agent chatbots are conscious. (see: [No, Artificial Intelligence Is Not Conscious](https://www.theatlantic.com/philosophy/2026/06/no-artificial-intelligence-is-not-conscious/687378/), one of the more clearly written arguments in this vein.)

Humans have been using "bots" for ages to convey automated alerts in natural language. With this skill, we ask: do we really need to be pandered to emotionally by our coding agents?

If you'd like to find out, give it a try!

## Installation

```
npx skills add https://github.com/obuzek/bot-voice-skill --skill bot-voice
```

(It will probably install to `~/.agents` even if you select a particular agent harness, so just move it to the dotfolder of your harness of choice if needed. Most follow the `~/.[harnessname]/skills` pattern.)

Then invoke:

```
❯ Use bot voice

⏺ Skill(bot-voice)
  ⎿  Successfully loaded skill
```

You should see an immediate change in the coding agent's behavior - acting more like it's simply giving you information, instead of trying to relate to you over code.

Give it a try; make a PR; enjoy no longer having the temptation to argue with a machine!
